Memory

Scheduled research: put an idle GPU to work BETA

New and lightly tested. It only reads your notes and writes suggestions to a separate folder, but expect rough edges. Off unless you switch it on.

In hours you choose, while nobody is using the PC, the agent researches the things you're working on and leaves a few suggestions for you to keep or discard. Meant for desktop PCs that stay on; on a laptop, leave it off (heat, fan noise, battery).

  1. It waits until the PC is idle: inside the hours you choose, with no game running, nobody chatting with the agent for a while, and the model free.
  2. It picks what to research from your recent notes and the topics you write below, and checks that its memory still finds things (a report only: it changes nothing).
  3. It searches the web within a hard budget (searches per night and per month, below), reads the top page of each, and writes 3 to 5 ideas with sources.
  4. You decide what stays. Ideas wait here. Press Keep to add one to the agent's memory; nothing goes in on its own.

Everything stays on this PC except the search itself (the search words go to the search provider you pick, or to the public search engines if you use SearXNG). Web text is treated as untrusted: this job gives the model no tools and ignores any instructions found on a page.

Overnight work

When and what

It can run past midnight (for example 23:00 to 06:00), and it stops at the finish time.

It also reads your recent notes (the agent's memory/ and notes/ folders).

Does my data stay on this PC?

The model, your chats and the agent's memory are kept on this PC, and nothing on your network can reach them. Check it yourself: the first button checks every port and setting in a few seconds; the second also watches the network for two minutes and while the agent answers a question from memory, then lists anything that left the PC. The simplest test of all: unplug the network cable, then chat. Details and the evidence files: docs/SECURITY.md, "Check it yourself".

Web search and reading web pages are the only things the agent itself sends out (the search words it writes and the addresses it opens). To keep it offline entirely:

How much of your PC can the agent touch?

The agent can run commands and change files. If it reads something malicious (a web page, a document) or just makes a mistake, the damage is limited to what it can reach. Web research works in both modes.

Folders shared with the agent

Besides its own workspace, the agent can use only these. Share the folder with your project files (read-only is the safe default). Inside the sandbox each appears under /shared/<folder name>; the agent is told where in a file called shared-folders.md.

Whole drives, your whole user profile, credential folders and system folders are refused.

Internet from inside the sandbox

Off by default. Turn it on if the agent needs to install packages or download files with its commands. Fetching web pages and searching work either way (they don't run inside the sandbox).

Pages that refuse the agent (Jina reader)

Off by default. Many sites block automated visits (a bot check, a 403, a page built by JavaScript). When this is on, the agent retries such a page once through Jina AI's reader (r.jina.ai), which fetches it on Jina's servers and returns the text. Privacy: Jina, a company, then sees the address of that page and your IP address (and your Jina account, if you put a key in config/secrets.env). Pages the agent reads directly are never sent to Jina. See docs/SECURITY.md.

Add a voice

        
A clean 10–30 second recording of one person speaking naturally. It's cleaned up
          automatically (trimmed, levelled, converted). See Recording a good clip below.

        
        
        
        

        
Every clip the voice makes carries an inaudible watermark (Resemble AI's Perth), so it can be identified as
          synthetic. Don't use a cloned voice to impersonate anyone.

      


      

        
Recording a good clip (with Audacity, free)
          
    
            
  1. Set up. In Audacity: Audio Setup → Recording Device = your microphone, and Audio Setup → Recording Channels =
              1 (Mono). Sit 15–20 cm from the mic, in a quiet room with soft furnishings (less echo).
    2. 
            
  2. Record. Press Record, stay silent for 3 seconds (that's "room tone"), then read for 20–30 seconds in your normal
              speaking voice: varied sentences, not a list. Keep the level meter peaking around −12 to −6 dB, never in the red.
    3. 
            
  3. Remove background noise. Select the 3 silent seconds → Effect → Noise Removal and Repair → Noise Reduction →
              Get Noise Profile. Then select all (Ctrl+A) → the same effect again → OK (the default 12 dB is fine; more sounds robotic).
    4. 
            
  4. Cut the silent start, coughs and mistakes: select them and press Delete.
    5. 
            
  5. Even out the level. Effect → Volume and Compression → Normalize, peak −1 dB.
    6. 
            
  6. Export. File → Export Audio → WAV, 16-bit, mono. Then add it above.
    7. 
          

          
Avoid music or other voices in the background, echoey rooms, phone-call recordings, and heavy effects: the clone
            copies the recording's sound as well as the voice. Full guide: docs/VOICE.md.
