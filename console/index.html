Model profiles

Each profile is one file in models/. Switching relaunches the model, rewrites the agent's config to match, and benchmarks it (1–3 minutes; chat pauses meanwhile). If the new model fails to start, it rolls back automatically.

Creates models/<name>.env from an existing profile. Pick the base closest to your model (same family is best). Then download it, switch to it and benchmark.

Voices

Add a voice

A clean 10–30 second recording of one person speaking naturally. It's cleaned up automatically (trimmed, levelled, converted). See Recording a good clip below.

Every clip the voice makes carries an inaudible watermark (Resemble AI's Perth), so it can be identified as synthetic. Don't use a cloned voice to impersonate anyone.

Talk to your agent

Recording a good clip (with Audacity, free)
  1. Set up. In Audacity: Audio Setup → Recording Device = your microphone, and Audio Setup → Recording Channels = 1 (Mono). Sit 15–20 cm from the mic, in a quiet room with soft furnishings (less echo).
  2. Record. Press Record, stay silent for 3 seconds (that's "room tone"), then read for 20–30 seconds in your normal speaking voice: varied sentences, not a list. Keep the level meter peaking around −12 to −6 dB, never in the red.
  3. Remove background noise. Select the 3 silent seconds → Effect → Noise Removal and Repair → Noise Reduction → Get Noise Profile. Then select all (Ctrl+A) → the same effect again → OK (the default 12 dB is fine; more sounds robotic).
  4. Cut the silent start, coughs and mistakes: select them and press Delete.
  5. Even out the level. Effect → Volume and Compression → Normalize, peak −1 dB.
  6. Export. File → Export Audio → WAV, 16-bit, mono. Then add it above.

Avoid music or other voices in the background, echoey rooms, phone-call recordings, and heavy effects: the clone copies the recording's sound as well as the voice. Full guide: docs/VOICE.md.
